ปลดล็อกประตูช่วยชีวิต

🚨 พบจุดบกพร่อง (Bug)! ระบบเปิดประตูติดขัดเนื่องจากโค้ดสลับลำดับ การ "Debugging" คือการหาและแก้ไขข้อผิดพลาด เลือกคำตอบที่เรียงลำดับโค้ดล็อกประตูได้ถูกต้องเพื่อช่วยผู้รอดชีวิต!

โค้ดที่มีข้อผิดพลาด (Bug Detected):
  1. 1. ใส่รหัสผ่านความปลอดภัย (Input Security Code)
  2. 2. เปิดประตูสุญญากาศ (Open Airlock Door)
  3. 3. ตรวจสอบลายนิ้วมือ (Scan Fingerprint) ← ผิดลำดับ! (ต้องตรวจก่อนใส่รหัส)

สรุปความรู้: แนวคิดเชิงคำนวณ (Computational Thinking)

  • 1. Decomposition: การแตกปัญหาใหญ่ออกเป็นปัญหาย่อยๆ เพื่อซ่อมแซมได้ตรงจุด
  • 2. Abstraction: การเลือกเฉพาะสาระสำคัญ ละทิ้งรายละเอียดที่ไม่เกี่ยวข้อง
  • 3. Pattern Recognition: การสังเกตรูปแบบและลักษณะร่วมเพื่อจัดหมวดหมู่
  • 4. Algorithm Design: การออกแบบลำดับขั้นตอนการทำงานอย่างชัดเจน
  • 5. Debugging: การค้นหาและแก้ไขข้อผิดพลาดของโปรแกรม
